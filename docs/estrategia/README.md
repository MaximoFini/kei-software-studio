- Agregar el permiso `instagram_manage_insights` a la app de Meta y regenerar el token (sin eso `scripts/insights_reels.py` solo rankea por likes/comentarios).
- Escuchar las muestras de voz y elegir.
- Verificar en la app si hay opción de promover trial reels (cuenta < 1.000 seguidores).
